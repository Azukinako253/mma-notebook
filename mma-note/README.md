# MMA NOTEBOOK

個人的な MMA（総合格闘技）トレーニングノートをまとめた、シングルページの静的 Web アプリです。
打撃・組み・寝技の3カテゴリをタブで切り替えながら、技術メモや写真を記録できます。

## 特徴

- **タブ切り替え**：打撃 / 組み / 寝技の3タブで内容を整理
- **技術カード・コンビネーション一覧・使える技一覧（テーブル）** で情報を構造化
- **画像アップロード**：各タブに写真参照エリアがあり、選択した画像をその場でサムネイル表示（ブラウザ内のみ、保存はされません）
- **フリーノート**：`contenteditable` の自由記述メモ欄（こちらも保存はされません）
- 外部サービス・バックエンド不要の純粋な静的サイト（HTML / CSS / JS のみ）

## ディレクトリ構成

```
mma-note/
├── public/
│   ├── index.html         # mma-notebook.html へ即リダイレクトする入口
│   ├── mma-notebook.html  # 本体（タブ・カード・テーブルなどのUI）
│   ├── style.css          # スタイル（CSS変数でテーマカラーを管理）
│   └── script.js          # タブ切り替え・画像アップロードのロジック
├── tests/
│   └── smoke.test.mjs     # ビルド成果物の簡易チェック
├── package.json
└── .gitignore
```

## セットアップ・使い方

Node.js 18 以上が必要です。

```bash
npm install
```

### 開発サーバーを起動

```bash
npm run dev
```

`public/` を `http://localhost:5173` で配信し、ブラウザを自動で開きます。

### ビルド

```bash
npm run build
```

`public/` の内容を `dist/` にそのままコピーします（バンドラ等は使用していません）。

### ビルド結果をプレビュー

```bash
npm run preview
```

`dist/` を `http://localhost:4173` で配信します。

### テスト

```bash
npm test
```

`mma-notebook.html` が正しく存在するか、ビルド後に `dist/index.html` が生成されているか等を確認するスモークテストです。

### ビルド＋テストをまとめて実行

```bash
npm run verify
```

## 注意事項

- アップロードした画像やフリーノートの内容は、ページを再読み込みすると消えます（永続化する仕組みは未実装）。
- バックエンド・データベースは持たない、完全にクライアントサイドのみのアプリです。
